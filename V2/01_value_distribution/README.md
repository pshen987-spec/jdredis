# 方案 1：Value 分布

实现位于 `../baseline/stress_test_baseline_v2.cpp`，与方案 2、3 共同组成 V2 基线。

- 预热：40 万 Key 的 Value 大小从 `N(200 KiB, 63.33 KiB)` 抽样，四舍五入到整数 KiB；落在 10～390 KiB 以外则重抽。每次预热写入带 1 秒 TTL。
- 正式阶段：普通 SET 的 Value **固定为 200 KiB**，不再抽样；APPEND 每次固定追加 200 KiB。
- `ABNORMAL_SET_SHARE` 默认 0；非零时按给定比例注入 512 KiB SET，用于方案 4 的拒绝规则测试。
- 每个大小对应一份按固定种子生成的伪随机二进制内容；预热时随机选大小，不在每条命令内重新生成整块内容。

这项定义了测试数据，不是单独的 Redis 优化。历史“正式 SET 也按正态分布抽样”的运行结果属于旧口径。
